# Portofolio Pribadi

Website portofolio satu halaman (single page) dengan navigasi tab di kiri dan widget-widget unik.

Dibuat menggunakan HTML, CSS, dan JavaScript vanilla tanpa build step.

## Struktur File

```text
portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   ├── main.js
│   ├── paintboard.js
│   └── player.js
├── assets/
│   ├── img/
│   │   ├── avatar-placeholder.svg
│   │   └── favicon.svg
│   └── music/
│       └── covers/
├── .nojekyll
└── README.md
```

## Isi Portofolio

Portofolio berisi beberapa section utama:

- About Me
- Skills
- Experience
- Projects
- Competition
- Certification
- Contact
- Fun Category

Selain section portofolio, website juga memiliki:

- Paintboard widget
- Mini MP3 player
- Inframe Web
- Tab navigation
- Responsive layout

## Tech Stack

- HTML
- CSS
- JavaScript
